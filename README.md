# 🌌 Cosmic Wonders: Daily Space Explorer ✨

An interactive, vibrant web dashboard that brings NASA's Astronomy Picture of the Day (APOD) directly to your screen daily. Discover nebulae, galaxies, and celestial phenomena with detailed scientific explanations provided by NASA astronomers.

---

## ✨ Features

- 🔭 **Daily APOD Fetch:** Automatically pulls the latest picture or video of the day from NASA's official APOD API.
- 🗓️ **Date Picker:** Travel back in time and view images from any date back to the APOD mission's inception (June 16, 1995).
- 🎲 **Cosmic Roulette (Random Day):** Discover a surprise astronomical event with a single click.
- 📸 **High-Definition Viewer:** Direct access to full-resolution images via the "View Full HD" link.
- 🎥 **Video Support:** Seamlessly embeds YouTube and NASA videos when the day's feature is not a static image.
- 🎨 **Glassmorphism UI:** Modern, dark-space aesthetic featuring vivid gradients, blur effects, and playful emoji accents.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic document structuring.
- **CSS3:** Glassmorphism, animations, responsive layout, and gradient typography.
- **JavaScript (ES6+):** Fetch API for asynchronous requests, dynamic DOM rendering, and date handling.
- **NASA APOD API:** Source of imagery, metadata, and scientific explanations.
