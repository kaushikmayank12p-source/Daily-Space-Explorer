# Daily Space Explorer

Daily Space Explorer is a small web app that shows NASA's Astronomy Picture of the Day along with a short explanation and related image details. It is designed to help you explore space in a simple and visually appealing way.

The app pulls data from the NASA APOD API and displays the current image or video, lets you browse older dates, and includes a random day feature for discovery.

## Features

- Shows the latest NASA APOD image or video
- Lets you choose a date and view past space photos
- Includes a random date option for exploring unexpected space content
- Opens a full-resolution image when available
- Supports video content from YouTube or NASA sources
- Uses a clean dark space-inspired interface

## Tech Stack

- HTML
- CSS
- JavaScript
- NASA APOD API

## Getting Started

### Prerequisites

You will need a NASA API key. You can get one for free from [api.nasa.gov](https://api.nasa.gov/).

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/Daily-Space-Explorer.git
   cd Daily-Space-Explorer
   ```

2. Open the project in a browser.

3. Add your NASA API key in the JavaScript file where the APOD request is made.

4. Run the app locally and start exploring space images.

## Notes

This project is a simple front-end app meant for learning and personal use. It works best when connected to the NASA APOD API and a valid API key.
